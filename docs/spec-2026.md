5점 척도: 매우 그렇다 / 그렇다 / 보통이다 / 그렇지 않다 / 전혀 그렇지 않다

1. 연수의 내용 구성이 적합하다고 생각한다.
2. 강사가 전문성을 갖추었다고 생각한다.
3. 연수 시간은 적합하다고 생각한다.
4. 연수 신청 및 이수 처리 등의 과정이 원활했다고 생각한다.
5. 연수 장소 및 강의실은 적합하다고 생각한다.
