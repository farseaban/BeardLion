# UI 시안 A · B · C

교(원)감 대상 안내 사이트의 화면 시안 세 가지입니다. 장학관 검토용으로 만들었습니다.
어느 안도 아직 확정이 아닙니다. 현재 브랜치 코드는 셋 중 어느 것도 아닌 중간 상태입니다.

## 세 안을 가른 기준

바탕색·강조색·모서리 세 축을 모두 다르게 잡았습니다. 한 축만 바꾸면 세 안이 한 가족처럼
보여 고르는 의미가 없어지기 때문입니다.

| 축 | A안 한지 문서형 | B안 야간 화면 | C안 흰 바탕 미니멀 |
|---|---|---|---|
| 바탕 | 한지색 `#f4ecdc` | 짙은 남회색 `#161c22` | 순백 `#ffffff` |
| 카드 | `#fdf8ee` | `#1f272f` | 흰색(테두리로만 구분) |
| 강조 | 주홍 `#a8321f` | 금색 `#f5c04a` | 청록 `#0f5f57` |
| 본문 글자 | 먹색 `#241f1b` | 흰빛 `#eef2f5` | 먹청색 `#10161c` |
| 모서리 | 각짐 0px | 둥금 16px | 살짝 둥금 8px |
| 첫 화면 | 큰 사진 한 장으로 열고 아래 3칸 | 2×2 격자 | 세로 큰 사진 2장, 여백 넓게 |

## 세 안이 공통으로 지키는 것

장학사 지시 다섯 가지는 세 안 모두 동일하게 적용했습니다.

- 본문 17px, 줄간격 1.7
- 보조 문구 15px 이상, 옅은 회색 글자 없음
- 하단 메뉴 60px, 바깥 링크 단추 56px, 되돌아가기·전화 48px 이상
- 하단 메뉴는 한글 이름 15px 굵게, 아이콘은 21px 보조
- 연수 일정은 2단 목록(시간 / 내용·장소)

## 대비 (WCAG 2.1 계산식)

| | 본문 대 바탕 | 강조 대 바탕 | 강조 위 글자 |
|---|---|---|---|
| A안 | 약 16:1 | 약 6.2:1 | 약 6.7:1 |
| B안 | 약 13.5:1 | 약 9.0:1 | 약 11.2:1 |
| C안 | 약 17:1 | 약 7.5:1 | 약 7.5:1 |

셋 다 본문 기준 4.5:1을 넘습니다. 계산으로 확인했고 실기기 측정은 하지 않았습니다.

## 각 안의 약점

**A안** — 한지색 바탕이 사진의 파란 하늘과 대비가 약합니다. 각진 모서리가 딱딱해 보일 수 있습니다.

**B안** — 짙은 바탕은 실내에서 눈이 편하지만 야외 햇빛 아래에서는 화면 반사가 늘어 오히려
읽기 어려울 수 있습니다. 9.30 일정 대부분이 야외입니다. 이 점은 실기기로 확인해야 합니다.

**C안** — 흰 바탕이라 배터리를 더 쓰고, 햇빛 아래에서 눈부실 수 있습니다. 장식이 거의 없어
밋밋하다는 의견이 나올 수 있습니다.

## 적용 방법

세 안 모두 현재 브랜치에 반영되어 있지 않습니다. 고른 뒤 해당 패치를 적용합니다.

```
git apply docs/ui-시안-A-한지문서형.patch     # 또는 B, C
npm run lint && npm run build
```

되돌리려면 `git apply -R <같은 파일>`.

패치는 `tailwind.config.js`(색·모서리 토큰)와 `src/training/`의 화면 코드를 바꿉니다.
문구·일정·링크가 담긴 `src/training/content.js`는 건드리지 않으므로 어느 안을 골라도
내용은 그대로입니다.

## 아직 확인하지 못한 것

- **사진.** 세 시안의 사진은 모두 자리 이미지입니다. 실제 사진의 색만 옮겨 담았습니다.
  실제 사진이 들어가면 인상이 달라집니다. 특히 B안(짙은 바탕)은 사진이 도드라지므로
  차이가 클 수 있습니다.
- **야외 가독성.** 세 안의 바탕색이 크게 달라 햇빛 아래 결과도 다릅니다. 휴대전화로
  직접 열어 보고 판단해야 합니다.
