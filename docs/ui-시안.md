# UI 시안 A · B · C

교(원)감 대상 안내 사이트의 화면 시안 세 가지입니다.

**2026. 9. 11. A안으로 정했습니다. 브랜치 코드는 A안입니다.**
B안과 C안 패치는 되돌아갈 수 있도록 그대로 둡니다.

## 세 안이 갈리는 지점

**색은 세 안이 똑같습니다.** 색을 먼저 고르면 구조가 안 보이기 때문에 일부러 묶어 두었습니다.
다른 것은 화면 구조와 탐색 방식뿐입니다.

| | A안 한 장 스크롤 | B안 큰 타일 허브 | C안 시간축 하나 |
|---|---|---|---|
| 화면 수 | 1개 | 5개 + 장소 소개 | 1개 |
| 탐색 | 위에서 아래로 내림 | 첫 화면 타일 → 들어감 → 처음으로 | 내리다가 필요한 행만 펼침 |
| 고정 메뉴 | 맨 위 바로가기 띠(글자) | 없음 | 없음 |
| 첫 화면 | 표지 + 일정 요약 | 큰 타일 4개가 곧 메뉴 | 연수 전체 시간표 |
| 장소 소개 | 코스 아래 이어 붙음 | 따로 화면 | 그 시각 행을 펼치면 나옴 |
| 자료·폼 | 아래쪽 절 | 따로 화면 | 해당 시각에 매달림 |
| 은유 | 종이 안내장 | 큰 버튼 몇 개 | 오늘의 일정표 |

## 세 안이 공통으로 지키는 것

- 본문 17px, 줄간격 1.7
- 보조 문구 15px 이상, 옅은 회색 글자 없음
- 누르는 곳 48px 이상, 주요 단추 56px 이상
- 메뉴·단추는 한글 이름이 먼저, 아이콘은 보조
- 장식 절제, 색은 한 가지만

## 각 안의 성격과 약점

**A안 한 장 스크롤.** 어디를 눌러야 할지 고르지 않아도 됩니다. 종이 안내장을 그대로 옮긴
구조라 처음 여는 사람에게 가장 부담이 적습니다. 대신 페이지가 길어 원하는 곳으로 바로
가기 어렵고, 맨 위 바로가기 띠를 못 볼 수 있습니다.

**B안 큰 타일 허브.** 누를 곳이 네 개뿐이고 하나하나가 큽니다. 스마트폰이 익숙하지 않아도
헤맬 여지가 적습니다. 대신 무엇이든 보려면 반드시 두세 번 눌러야 하고, 전체를 한눈에
훑을 수 없습니다.

**C안 시간축 하나.** 연수 당일 "지금 뭐 하지"에 가장 빨리 답합니다. 모든 정보가 자기 시각에
매달려 있어 찾아다닐 필요가 없습니다. 대신 연수 전에 자료만 따로 보거나 장소만 훑어보기는
불리합니다. 시각과 무관한 항목(희망 음료 신청)은 맨 위에 따로 고정했습니다.

## 확정 뒤 고친 것

A안을 적용하면서 두 가지를 바꿨습니다.

**바로가기 띠를 맨 위에서 맨 아래로 옮겼습니다.** 화면 아래에 붙여 고정합니다.
한 장 스크롤은 문서가 9화면 분량(390px 폭에서 7,674px)이라 맨 위 띠는 곧 사라집니다.
아래 고정은 엄지가 닿는 자리이기도 합니다. 다섯 칸이 각각 78 × 60px입니다.

**코스 줄의 화살표를 오른쪽에서 아래쪽으로 바꿨습니다.** A안에는 장소 소개가
따로 있지 않고 같은 쪽 아래에 이어 붙습니다. 오른쪽 화살표는 다른 화면으로
넘어간다는 뜻이라 어긋납니다. 바깥 링크(패들렛·구글폼)만 오른쪽 화살표입니다.

## B안·C안으로 되돌리려면

```
git apply -R docs/ui-시안-A-한장스크롤.patch
git apply docs/ui-시안-B-큰타일허브.patch      # 또는 C
npm run lint && npm run build
```

위 두 가지 수정은 A안 전용이라 되돌릴 때 함께 빠집니다.

문구·일정·링크가 담긴 `src/training/content.js`는 패치가 건드리지 않습니다.
어느 안을 골라도 내용은 그대로입니다.

## 색은 아직 정하지 않았습니다

구조를 고른 다음에 색을 정하는 순서입니다. 한 번에 둘을 물으면 둘 다 흐려집니다.
지금 색은 짙은 남색(`#1d3552`) 한 가지입니다. 종이 바탕과 대비 11.2:1,
흰 글자를 얹으면 12.5:1로, 어느 쪽도 기준(4.5:1)을 크게 넘습니다.
바꾸려면 `tailwind.config.js`의 `accent`·`onAccent` 두 줄만 고치면 됩니다.

## 아직 확인하지 못한 것

- **사진 해상도.** 올려 주신 네 장 중 `images1.jpg`(약속정원)는 303×148로 작습니다.
  B안의 타일 배경(390×124)과 A안 첫 화면 격자에서 흐리게 보입니다. 최소 가로 800px
  이상으로 다시 구해야 합니다. 나머지 세 장은 쓸 만합니다.
- **사진 출처.** 네 장 모두 출처와 이용 조건을 확인하지 않았습니다. 공개 저장소이므로
  연수 전에 정리해야 합니다.
- **손에 쥐고 쓰는 느낌.** 스크롤 길이, 펼침 반응 같은 것은 그림으로 판단되지 않습니다.
  휴대전화로 직접 열어 보셔야 합니다.
