# UI 시안 A · B · C

교(원)감 대상 안내 사이트의 화면 시안 세 가지입니다. 장학관 검토용으로 만들었습니다.
어느 안도 아직 확정이 아닙니다.

## 세 안의 차이

| 항목 | A안 | B안 | C안 |
|---|---|---|---|
| 본문 글자 | 15px | 17px | 17px |
| 보조 문구 | 12~13px 옅은 회색 | 15px 짙은 색 | 15px 짙은 색 |
| 바탕색 | `#f3ead8` 따뜻한 종이색 | `#f4f2ed` 채도 낮은 종이색 | `#f3ead8` 따뜻한 종이색 |
| 강조색 | 주황 + 분홍·보라·하늘·초록 | 짙은 남색 하나 | 짙은 주황 하나 (`#9a3412`) |
| 하단 메뉴 | 색 원 안 아이콘이 큼, 한글 12px | 한글 15px 굵게, 아이콘 보조 | 한글 15px 굵게, 아이콘 보조 |
| 일정 표기 | 4열 표 | 2단 목록 | 2단 목록 |
| 버튼 높이 | 내용에 따라 다름 | 56px 이상, 모서리 각짐 | 56px 이상, 모서리 둥금 |
| 사진 | 흰 테 + 기울임(최대 6도) | 반듯한 격자, 기울임 없음 | 흰 테 + 기울임(1~2도) |
| 화면 제목 | 그림 기호 + 굵은 테두리 상자 | 단색 아이콘 + 왼쪽 띠 | 그림 기호 + 왼쪽 띠 |

## 설계 의도

**A안** — 전임자의 캔바 안내장 계열. 밝고 친근합니다. 초등 현장의 안내장 관습에 가깝습니다.

**B안** — 장학사 지시 다섯 가지(글씨 키우기, 대비 확보, 넉넉한 버튼, 한글 메뉴명, 절제된 장식)를
글자 그대로 반영했습니다. 결과적으로 공문 서식에 가까워졌습니다.

**C안** — A안의 색과 B안의 활자를 나눠 가진 안입니다. 색·장식과 글자 크기·대비는 원래 별개의
축인데 A안과 B안에서는 한 덩어리로 묶여 있었습니다. C안은 이를 분리해 따뜻한 색을 유지하면서
글자 크기와 대비를 확보합니다.

## C안 색 기준

흰 배경에서 본문 글자로 쓸 수 있는 짙기까지 주황을 내렸습니다.

| 이름 | 값 | 흰 배경 대비 | 쓰임 |
|---|---|---|---|
| `warm-800` | `#9a3412` | 7.3:1 | 주 강조. 글자·채움 모두 |
| `warm-700` | `#b45309` | 5.0:1 | 보조 글자 |
| `warm-200` | `#f3d9ae` | — | 테두리 |
| `warm-100` | `#fbebd3` | — | 옅은 바탕 |
| `ink` | `#1c1917` | 15:1 | 본문 |

A안의 `orange-500`(`#f97316`)은 흰 배경 대비가 3.0:1이라 본문 기준 4.5:1에 못 미칩니다.
C안이 같은 주황 계열이면서 더 짙은 이유입니다.

> 대비값은 WCAG 2.1 계산식으로 구했습니다. 실기기 측정은 하지 않았습니다.

## C안 적용 방법

C안은 아직 브랜치에 반영되어 있지 않습니다. 현재 브랜치는 B안 상태입니다.
C안을 택하면 다음과 같이 적용합니다.

```
git apply docs/ui-c안.patch
npm run lint && npm run build
```

되돌리려면 `git apply -R docs/ui-c안.patch`.

## 아직 확인하지 못한 것

사진이 세 안 모두 자리표시입니다. 실제 사진이 들어가면 첫 화면 인상이 달라집니다.
특히 A안과 C안의 기울인 사진 배치는 실제 사진으로 다시 봐야 판단할 수 있습니다.
